# Multi-Vendor E-Commerce Backend

A production-grade REST API built with Spring Boot, MySQL, and JWT Authentication.

## Tech Stack
- Java 17
- Spring Boot 3.2
- Spring Security + JWT
- Spring Data JPA + Hibernate
- MySQL 8
- Maven

## Architecture
MVC layered architecture: Controller → Service → Repository

## Modules
- Vendor management
- Product catalog
- Order processing
- JWT Authentication
- Role-based access control (CUSTOMER, VENDOR, ADMIN)
